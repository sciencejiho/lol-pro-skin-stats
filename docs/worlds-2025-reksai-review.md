# 2025 월즈 메인 이벤트 렉사이 검토 목록

메인 이벤트 [경기 원본](../data/worlds/2025-main-event/roster.json)에는 렉사이가 **15경기** 등장합니다. 아래 표의 스킨 칸은 아직 전부 비어 있습니다. 영상에서 챔피언을 실제로 확인하기 전에는 후보 스킨을 경기별 사용 기록으로 세지 않습니다.

[2025 월즈 스킨 관찰 기록](https://www.reddit.com/r/leagueoflegends/comments/1ox1hn9/fun_facts_about_skins_at_worlds_2025/)은 플레이인을 포함한 대회 전체에서 렉사이의 여섯 외형 중 네 가지가 쓰였으며 기본 스킨과 Pool Party Rek'Sai는 쓰이지 않았다고 보고합니다. [Riot의 렉사이 스킨 목록](https://www.leagueoflegends.com/en-gb/champions/reksai/)과 맞추면 **보고된 후보**는 Eternum, Blackfrost, Elderwood, Primordian Rek'Sai입니다. 관찰 기록은 각 후보를 어느 경기에 연결할지 알려주지 않습니다. 특히 Doran에게 Eternum Rek'Sai를 기재했지만 Doran의 렉사이 경기는 두 번이므로 둘 중 어느 경기인지 단정할 수 없습니다.
